# Agent-1 Handoff: UX Planning Review

## 결론

현재 기획은 "분석 참고 후 수동 구매" 원칙은 명확하지만, 사용자가 실제로 편하게 쓰기 위한 행동 흐름은 아직 끊기는 지점이 있다. 특히 웹과 모바일 모두에서 "무엇을 먼저 해야 하는지", "추천 결과를 어떻게 바로 활용하는지", "가맹점 정보가 왜 분리되어 있는지"가 첫 화면만으로 충분히 설명되지 않는다.

## 우선 수정 필요

### 1. 첫 화면의 핵심 행동이 분산됨

- 기획은 첫 진입에서 최신 추천 실행과 수동 구매 원칙을 바로 이해하게 하려 한다. `docs/storyboard.md:48`
- 실제 웹 첫 화면은 가맹점 연구 페이지 링크가 상단에 먼저 강하게 노출되고, 추천 생성 액션은 아래 컨트롤 섹션에 내려가 있다. `web/index.html:11`
- 모바일도 첫 화면에서 추천 생성이나 수동 구매 보조 행동이 없고, 데이터 상태와 최신 추첨 결과만 보인다. `flutter_app/lib/main.dart:125`

권장 방향:
- 첫 화면 최상단 CTA를 "추천 생성/다시 생성" 하나로 수렴.
- "수동 구매 전용" 배지를 헤더 고정 정보로 올리기.
- 가맹점 연구는 2차 탐색 액션으로 낮추기.

### 2. 사용자가 추천 결과를 실제 구매 행동으로 옮기는 경로가 약함

- 기획은 장면 6에서 사용자가 추천 번호를 보고 수동 입력까지 이어지도록 상정한다. `docs/storyboard.md:78`
- 웹은 수동 입력 보조판이 있으나, 첫 화면 정보 구조상 추천 번호 세트와 입력 보조판이 분리돼 있어 초행 사용자는 흐름을 이해하기 어렵다. `web/index.html:69`
- 모바일은 추천 번호 생성 기능 자체가 없어서 "오프라인으로 읽는 앱"은 되지만 "실제 사용 행동을 돕는 앱"은 아직 아니다. `flutter_app/lib/main.dart:149`

권장 방향:
- 웹: 티켓 카드에서 바로 "입력 보조판 열기/복사"를 1차 액션으로 강조.
- 모바일: 최소한 추천 세트 보기, 복사, 회차 기준 설명까지는 포함.
- 두 플랫폼 모두 "이 다음엔 공식 사이트나 오프라인 용지에 수동 입력" 문구를 결과 가까이에 재배치.

### 3. 가맹점 정보의 가치가 설명되기 전에 별도 페이지로 분리됨

- 기획상 가맹점 보드는 추천 결과에 현실 장소감을 주는 보조 맥락이다. `docs/storyboard.md:72`
- 실제 웹은 가맹점 연구를 별도 페이지로 완전히 분리했고, 메인 화면에서는 왜 이 페이지를 봐야 하는지 맥락이 약하다. `web/index.html:102`
- 사용자는 추천 번호를 보러 왔다가 갑자기 별도 지도 페이지 링크를 만나면 우선순위를 헷갈릴 수 있다.

권장 방향:
- 메인 화면에 최근 회차 가맹점 1~2개를 미리보기로 노출.
- "더 보기" 링크로 상세 페이지 이동.
- 별도 페이지 분리는 유지하되, 분리 이유를 "탐색량이 많아 상세 화면으로 분리"라고 명시.

## 중간 우선순위

### 4. 시드와 생성 규칙이 사용자 친화적으로 해석되지 않음

- 기획은 주간 기본 시드와 규칙 요약을 설명 레이어로 활용하려 한다. `docs/storyboard.md:54`
- 실제 웹 입력값은 숫자 시드만 바로 노출되어 있고, 왜 바꿔야 하는지 또는 비워두면 어떻게 되는지 보이지 않는다. `web/index.html:34`

권장 방향:
- 시드 아래에 "비워두면 주간 기본값 사용" 설명 추가.
- "이번 주 기본 추천"과 "직접 시드 지정"을 분리해 선택 부담을 줄이기.

### 5. 모바일 기획은 데이터 관리 중심이고 사용자 가치 서사가 약함

- 현재 모바일 앱은 번들 로드, 업데이트 확인, 최신 추첨, 최근 가맹점 회차 미리보기에 집중돼 있다. `flutter_app/lib/main.dart:154`
- 하지만 README는 실행 전에 데이터 생성, Flutter 프로젝트 생성, 의존성 설치를 요구해 사용 준비 비용이 높다. `flutter_app/README.md:11`

권장 방향:
- 모바일 포지셔닝을 "오프라인 결과 뷰어"로 명확히 고정하거나,
- 아니라면 추천 번호 소비 흐름까지 넣어서 제품 목적과 화면 구성을 맞추기.

## Agent-1 제안 작업

1. 메인 웹 IA를 재정렬해서 상단 CTA를 추천 생성 중심으로 바꾸기.
2. 웹에서 추천 결과와 수동 입력 보조판 사이 연결 문구/버튼을 강화하기.
3. 메인 화면에 가맹점 미리보기 카드를 추가하고 상세 링크는 2차 액션으로 내리기.
4. 모바일은 범위를 재정의하기.
   - 옵션 A: 오프라인 데이터 뷰어로 문구/화면을 정리
   - 옵션 B: 추천 번호 소비 흐름까지 확장

## 메모

이번 검토는 사용자 불편 가능성 중심의 기획 리뷰다. 코드 품질 이슈보다 정보 구조와 행동 흐름의 우선순위를 본 것이다.
